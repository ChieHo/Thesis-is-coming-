= Thesis is coming!

Fullstack web application for matching students with thesis supervisors
(HHU Programmierpraktikum 2 project)

Features

*Browse and search
**supervisor profiles with tags and specializations
**thesis topics with filtering by field, prerequisites and supervisor

*Matching system
**students enter their completed courses and interests
**System find compatible supervisors and topics

*Supervisor profiles with files (PDF, ZIP, Markdown), links and field tags
*Thesis topics with descriptions (rendered Markdown), prerequisites, files and links

*Role-based access
**Students
**Supervisors (Teachers)
**Admins

*Dashboards
**Admin dashboard for managing supervisor roles
**Teacher dashboard for managing own profile and topics

*Authentication via GitHub OAuth2
*Markdown files rendered as HTML directly in the browser

Tech Stack

Backend: Spring Boot, Spring Web, Spring Data JDBC, Spring Security (OAuth2 via GitHub)
Frontend: Thymeleaf, Pico CSS
Database: PostgreSQL
Build: Gradle (multi-module)

Architecture
Onion Architecture with Gradle submodules enforced via ArchUnit. Modules: Profil (domain + persistence + web), Utility (shared utilities).
Setup

Prerequisites – make sure the following are installed:

Java 21
Docker & Docker Compose
Git


Clone repository:
git clone
Start database:
docker compose up -d
Configure GitHub OAuth2 – add your GitHub OAuth App credentials to application.properties or as environment variables:

   spring.security.oauth2.client.registration.github.client-id=...
   spring.security.oauth2.client.registration.github.client-secret=...

Start application:
./gradlew bootRun
Open in browser:
http://localhost:8080
